# ร้านโปสเตอร์สำหรับพอร์ตสมัครงาน Full-stack

## เป้าหมาย
ให้ผู้สัมภาษณ์ลองซื้อโปสเตอร์จำลอง แล้วตรวจคำสั่งซื้อและสต็อกในหลังร้านได้ในหนึ่งนาที ทั้งบนมือถือและเดสก์ท็อป

## แนวทางที่เลือก
ผู้ใช้เลือก Full-stack ที่มีหน้าจัดการสินค้า แนวทาง Frontend ที่เน้นหน้าร้านและตะกร้ามีขอบเขตเล็กกว่า แต่การมีฐานข้อมูลช่วยให้ผู้ชมตรวจผลของการสั่งซื้อผ่านหลังร้านได้

## ขอบเขตที่เสนอ
- หน้าร้านภาษาไทย ใช้เงินบาท มีภาพพิมพ์ตัวอย่าง 6 แบบ กรองตามสไตล์และเลือกขนาด A4 หรือ A3 พร้อมราคาและสต็อกแยกตามขนาด
- ตะกร้าแก้จำนวนและลบรายการได้ ยืนยันการสั่งซื้อจำลองโดยใช้ชื่อเล่น ไม่เก็บข้อมูลบัตรหรือที่อยู่ แสดงเลขคำสั่งซื้อและยอดรวม
- หลังร้านเดโมดูคำสั่งซื้อและปรับสต็อกของแต่ละขนาดได้ มีปุ่มเข้าจากหน้าร้าน สร้างพื้นที่เดโมแยกตามเบราว์เซอร์ด้วย session cookie เพื่อให้ผู้ชมแต่ละคนทดลองได้อิสระ
- เซิร์ฟเวอร์คำนวณราคาจากฐานข้อมูล ตรวจจำนวนคงเหลือ บันทึกคำสั่งซื้อและตัดสต็อกในธุรกรรมเดียว การส่งซ้ำด้วยรหัส checkout เดิมคืนคำสั่งซื้อเดิม ของหมดระหว่างสั่งซื้อให้แจ้งผู้ซื้อและเปิดให้แก้จำนวน

## ข้อเสนอด้านเทคนิคและการส่งมอบ
ใช้ Next.js, TypeScript และ SQLite ในเครื่อง เก็บข้อมูลข้ามการรีสตาร์ต มีคำสั่งเริ่มต้นใน README พร้อมขั้นตอนทดลองตั้งแต่หน้าร้านถึงหลังร้าน การรับเงินจริง การจัดส่ง และการเผยแพร่ขึ้นโฮสต์อยู่นอกขอบเขตเวอร์ชันนี้ ผู้พัฒนาเลือกรูปสินค้า สี และโครงหน้าที่เหมาะกับการใช้งานบนมือถือได้
